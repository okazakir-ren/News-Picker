Next.js → React (Vite) + Rails API への段階的移行ガイド

React 19 + Vite TanStack Query Rails 7 API Devise Token Auth Sidekiq AWS CDK

このガイドについて

  • React: 上級者向け - ポイントのみ解説（TanStack Query連携、認証フロー等）
  • Rails: 中級者向け - devise_token_auth, Sidekiq, Service層を丁寧に
  • AWS: 中級者向け - CDKによるECS/RDS/CloudFront構成をステップバイステップで
  • 各Stepは独立して読める構成。上から順に進めることを推奨
01
プロジェクト基盤セットアップ
モノレポ構成の作成、Rails API-onlyプロジェクトの初期化、Vite + React + TypeScriptの初期化、Tailwind CSS + shadcn/uiのセットアップ。
rails new --api Vite shadcn/ui Tailwind CSS 4 Rails: 詳細 React: 軽め
02
認証システム（Devise Token Auth）
devise_token_authのセットアップ、Userモデル・マイグレーション、認証API実装、CORS設定。フロントエンドではfetchラッパーとAuthContextを構築。
devise_token_auth CORS トークン管理 AuthGuard Rails: 詳細 React: ポイントのみ
03
Interest CRUD

ランディングページ & 仕上げ
ランディングページの移植、ルーティング全体テスト、エラーハンドリング統一、レスポンシブ対応確認。Next.js固有コードの置換パターン集。
